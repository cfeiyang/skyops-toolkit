# 月度项目分配管理（MPAM）

> Monthly Project Allocation Management

单人使用的项目号分配工具：登录 → 手动导入你自己的 Excel → 月历选月份 → 选人 → 输项目号，程序判重后直接写回**那个源文件**。

**规则**：同一人员、同一月份、**同一个项目号**只允许一次。
同一个人在同一个月可以分配多个**不同**的项目号；只有重复的项目号才被拦截。进入下个月就是新周期，历史不被清除。

## 运行

双击 `MPAM.cmd`（用 pythonw 启动，**不弹黑窗口**），或：

```powershell
cd D:\Projects\MPAM
python main.py
```

启动后先出**登录界面**（默认账号 `root` / 密码 `123456`），登录后进入主界面。
主界面**不会自动弹文件选择框**，等你手动点右上「导入 Excel…」挑文件；
选定后所有分配/修改都直接写回这个文件，并在同目录 `backup\` 里自动留备份。

### 登录账号

默认 `root / 123456`，存在程序目录的 `config.json`（首次启动自动生成）：

```json
{
  "username": "root",
  "password": "123456"
}
```

改这个文件就能换账号密码。连续输错 3 次程序退出。

调试时想跳过导入、直接用内置模拟数据（仍需登录）：

```powershell
python main.py --mock            # 用模拟数据启动
python main.py --mock --reset    # 重新生成模拟数据
```

依赖只有 `openpyxl`：

```powershell
python -m pip install openpyxl
```

> 双击启动没有窗口弹出？说明启动时报错被隐藏了 —— 在终端里跑 `python main.py` 能看到具体错误。

## 界面

两个页签：

**① 分配**

```
[导入 Excel…]
┌ 分配 ┬ 检索 ┐
  分配月份 [2026年11月 ▼]   分配人员 [张三____▼]   [＋ 人员]
  原项目号 [不修改▼]   项目编号 [____▼]   [＋ 项目号] [确认分配] [修改项目号]
  ⚠ 张三 · 2026年11月 已分配过项目号「67890」，不能重复分配
  2026年11月 分配情况　3/4 人已分配
    人员   项目号           状态     最近分配
    张三   12345、67890     2 个     2026-11-06 09:30:00
```

- **月份用月历选**：点「2026年11月 ▼」弹出 12 个月的面板，◀ ▶ 切年份，点月份即选中；**默认就是当天所在的月份**；选到表里还没有的月份会自动建列。
- **人员可输入**：下拉自动载入所有人名，边打字边**自动展开下拉**（前缀命中的排前面、包含的排后面）；输入一个表里没有的名字再点「确认分配」，会自动加进 A 列并完成分配。
- **项目号可输入/可新增**：下拉自动载入文件里已有的项目号，也可以直接输入新号；点「＋ 项目号」把新号登记进「项目号」台账表，之后下拉里就有它了。
- **新增**：原项目号留「不修改」，输项目号 → 「确认分配」。
- **修改**：原项目号里选一个旧号，输新号 → 「修改项目号」；只能改成该人该月还没用过的号。
- **判重**：只有「该人该月已分配过这个号」才拦截；已有别的号不影响。

**② 检索**（整块是一张白色卡片，结果区更大）

```
检索方式 (•)按人员  ( )按项目号
人员 [张____▼]   项目号 [67890 ▼]   [查询]
  月份        人员      项目号      分配时间
  2026年11月  张三      12345      2026-11-03 10:22:15
  2026年12月  张三      67890      2026-12-01 09:00:00
                                    人员「张」：共 3 条记录
```

- 两个输入框都是**可输入的下拉**：人员自动载入所有人名，项目号自动载入文件里已有的全部项目号；边打字边**自动展开下拉**（前缀命中优先），**输入即查、不用点「查询」**。
- **按人员**：列出姓名**包含**所输内容的人、其**所有月份**的项目号；
- **按项目号**：列出该号出现在**哪些月份、给了谁**，**一字不差**匹配；输 `6789` 查不到 `67890`，但会提示「相近的有：67890」；
- 切换到检索页会按当前条件自动刷新，切页不卡。

## 导入兼容

- 工作表名不叫「分配汇总」也能导入（优先用「分配汇总」，否则用第一个工作表）；
- 表头上方有标题行也能识别（自动找第一行含月份表头的行，最多看前 6 行）；
- 月份表头支持 `2026年11月`、`2026-11`、`2026/11`、`2026.11` 以及 Excel 日期单元格；
- 表头是**日期**（存 `2026-01-01`、靠格式显示成「2026年1月」）也支持；新建月份列时按**同格式日期**写入，不会变成文本；
- 项目号统一按文本写入，`0010001` 这种前导零不会被吃掉；
- 导入失败会弹窗说明原因（例如找不到月份列）。

## 自动处理

- **同号高亮**：同一个月里出现多次的项目号，所在格子自动标浅黄（每次保存时重算，不碰你手填的其它底色）；
- **自适应列宽**：人员列和各月份列按内容调整，**只加宽、不压窄**（保留模板原有列宽），上限 60；
- **自动建列**：选中的年月在表里不存在时，在正确位置插入一列并复制相邻列样式（合并单元格会跟着移动）；
- **备份 + 原子保存**：每次写入前存一份到 `backup\`，保存走「临时文件 + 原子替换」。

明细表 `分配明细`（若工作簿里没有则自动创建）：`月份 | 姓名 | 项目号 | 操作 | 原项目号 | 操作时间`，每次分配/修改追加一行。

项目号台账 `项目号`（点「＋ 项目号」时自动创建）：单列登记所有项目号，作为分配/检索下拉的候选池；导入的老表没有这张表也能用（候选自动从分配格里读）。

## 目录

```
MPAM\
├─ main.py                 入口：登录 → 空态主界面 → 手动导入
├─ excel_store.py          全部 Excel 读写、判重、高亮、列宽、检索
├─ mock_data.py            模拟数据生成（--mock 用）
├─ ui.py                   tkinter 界面（换 PySide6 只改这一个文件）
├─ selftest.py             无界面自检
├─ config.json             登录账号（首次启动自动生成，默认 root/123456）
├─ data\                   仅 --mock 时生成
├─ MPAM.cmd
└─ README.md
```

## 自检

```powershell
python selftest.py
```

覆盖：同月多项目、同号拦截、修改、高亮、自适应列宽、双向检索、项目号清单、人员模糊检索、导入表头识别、新增人员、落盘。
