# 月度项目分配

## 打开软件

- 在仓库根目录双击 `SkyOpsToolkit.cmd`，输入 `1` 后按回车打开月度项目分配。
- 发给 Windows 同事时使用 `dist/月度项目分配.exe`。同事直接双击即可，也可以将现有工作簿另发给他导入。
- 源码开发可双击 `MPAM.cmd`，或在 `SkyOps` 环境中执行 `python MPAM/main.py`。

第一次打开时创建本机管理员。管理员通过右上角「当前账号 → 账号管理」创建、启用、停用和重置账号。新增或重置后，使用者在首次登录时设置自己的密码。

## 导入、修改、交接

1. 「导入 Excel」从 `.xlsx` 读取分配并导入本地数据库。点击「预览数据」可只读查看数据库当前内容生成的完整工作簿（包含全部工作表）；预览也提供导入和导出入口。表格采用人员为行、月份为列。月份可以是 Excel 日期，也可以是 `2026年11月`、`2026-11` 等文本。
2. 在「分配数据」表格每个人的操作栏点击「新增分配」或「修改」。每个人每月只能有一个项目号，同一项目号可以分配给不同人员。导入数据中已有多项的人员会显示「需整理」，可选择保留一项，其余移除操作会记入变更记录。软件将分配和变更记录保存在本机 SQLite，原 Excel 只用于读取。
3. 项目标签优先读取 Excel 按项目号设置的颜色；没有对应规则的项目号使用由编号稳定生成的颜色，同一编号每次显示一致。
4. 月份选择旁可在「分配数据」和「变更记录」间切换，记录按当前月份显示，并可筛选人员、项目号或操作账号。历史表显示操作时间、操作人、人员、操作类型和项目号变化。原表自带的旧分配明细也可查看，缺少账号的旧记录显示「未记录」。
5. 需要交接时点「导出副本」，用一个新文件名输出最新分配，月份表头统一显示为 `2026年8月` 这种写法。Excel 导入即写入本地数据库，导出则从数据库生成 Excel 副本；两台电脑上的本地数据库独立。重复导入同一路径下内容相同的源文件会打开已有数据。

本机数据位于 `%LOCALAPPDATA%\SkyOps\MPAM\allocations.sqlite3`。关闭软件后可备份该文件。更换 EXE 后，软件继续从该目录读取数据。当前版本首次创建独立账号；旧版单账号配置文件不参与登录。

## 打包

在 `SkyOpsToolkit.cmd` 菜单输入 `4` 后按回车打包月度项目分配，生成 `dist/月度项目分配.exe`。开发环境需要在 `SkyOps` 中安装运行依赖和 PyInstaller：

```powershell
conda activate SkyOps
python -m pip install -r MPAM/requirements.txt
python -m pip install "PyInstaller>=6,<7"
python MPAM/packaging/build.py
```

用于演示时，运行 `python MPAM/main.py --mock`。示例使用独立的演示数据库。旧版 Excel 读写兼容性自检入口为 `python MPAM/tests/selftest.py`。

## 程序目录

| 位置 | 用途 |
| --- | --- |
| `MPAM.cmd`、`main.py` | Windows 双击入口和 Python 入口 |
| `app/` | 界面、数据库、Excel 读写和演示数据 |
| `assets/` | 图标、样式和图标许可 |
| `packaging/` | Windows EXE 打包 |
| `tests/` | Excel 兼容性自检 |
